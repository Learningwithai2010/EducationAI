# EducationAI

An iOS app designed to teach students how to use AI ethically and effectively for learning.

## Vision

EducationAI helps students move beyond copying answers and instead use AI as a tool for understanding, critical thinking, and academic growth.

**Core Philosophy:** AI should support thinking, not replace it.

## Goals

- Teach ethical AI usage in schoolwork
- Provide structured AI learning prompts that guide students to think, not just get answers
- Encourage deeper thinking instead of shortcut answers
- Build a student-first AI education platform

## Features (In Development)

- **AI Tutor Chat** — A chatbot with guardrails that refuses to just give answers. It guides students through problems step by step.
- **Smart Quiz System** — Custom quizzes that adapt to what you struggle with, with explanations for every wrong answer.
- **Study Session Planner** — Time-aware study plans that optimize based on how much time you have and what you need to review.
- **Progress Tracking** — Mistake pattern recognition and mastery tracking across topics.

## Tech Stack

- **Language:** Swift
- **Framework:** SwiftUI
- **IDE:** Xcode
- **Target:** iOS

## About

Built by a 15-year-old high school student learning Swift from scratch. This project documents the journey from first `print("Hello, world!")` to a real iOS application — using AI as a learning tool, not a crutch.

## Status

Currently in early development. Home screen and navigation structure complete. Core features being built incrementally.
